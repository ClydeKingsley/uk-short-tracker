# Support

Use the GitHub issue forms for reproducible bugs, public-data discrepancies, and
feature proposals. Search existing issues first.

Do not use public issues for security vulnerabilities, private financial data,
broker credentials, or an entire local data directory. See [SECURITY.md](SECURITY.md)
and [PRIVACY.md](PRIVACY.md).

This is community research software with no service-level agreement. The latest
release is the supported version. Financial or trading decisions remain with the
user; maintainers cannot provide personalised investment advice.
